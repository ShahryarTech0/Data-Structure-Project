# Ticket Booking System 🎟️

A console-based ticket booking application demonstrating core data structures and algorithms in C++. This project simulates a real-world ticket reservation system with efficient seat allocation and management.

## Key Features
- 🪑 **Dynamic Seat Allocation** using 2D arrays
- 🔍 **Search & Booking** with optimized algorithms
- 📝 **File-based Data Persistence** for bookings
- 📊 **Admin Dashboard** for managing events

## Tech Stack
- **Language**: C++
- **Data Structures**: Arrays, Linked Lists, Queues
- **Storage**: File handling (.dat files)
- **IDE**: Visual Studio/Dev-C++
